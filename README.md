# Dungeons & Kittens Table Kit

A mobile-friendly Next.js table companion for a Storyteller and players.

MVP scope:

- Join by table code or local cache
- Choose a Storyteller, character, or observer seat
- Storyteller all-character table view
- Per-character editable sheet
- 2d6 / 3d6 / 4d6 roller with one-die reroll
- Editable rules quick reference
- Local cache first, Supabase realtime-ready

## Local Run

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:3000`.
